# Simple Calculator

A basic Python script that performs standard arithmetic operations: addition, subtraction, multiplication, and division (with zero-division handling).

## 🚀 Usage

Run the script using Python:

```bash
python calculator.py

```

## 🛠️ Features

* `add(a, b)`: Returns the sum of two numbers.
* `subtract(a, b)`: Returns the difference between two numbers.
* `multiply(a, b)`: Returns the product of two numbers.
* `divide(a, b)`: Returns the quotient, or an error message if dividing by zero.
